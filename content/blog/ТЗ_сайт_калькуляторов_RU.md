# Техническое задание — Сайт финансовых калькуляторов

## Обзор проекта

Статический сайт с финансовыми калькуляторами на русском языке.
Целевая аудитория: русскоязычные инвесторы (в России, СНГ и Европе).
Цель: органический SEO-трафик + монетизация через партнёрские ссылки и AdSense.

---

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Хостинг**: Vercel (бесплатный тариф)
- **Язык**: TypeScript
- **Backend не нужен** — все расчёты выполняются на стороне клиента

---

## Дизайн

Стиль: строгий минимализм. Белый фон, чёрный текст, одна акцентная деталь.
Референсы: Notion, iA Writer, Stripe Docs.

### Цвета (CSS переменные)
```css
--bg:           #ffffff

--text-muted:   #888888
--accent:       #111111
```

### Типографика
- Все тексты: `Inter` (Google Fonts) — weight 400 / 500 / 600
- Числа и результаты: `JetBrains Mono` — моноширинный шрифт
- Размер базового текста: 16px
- Межстрочный интервал: 1.6

### Принципы дизайна
- Белый фон, светло-серые карточки
- Минимум декоративных элементов
- Никаких теней, градиентов, иконок — только типографика и линии
- Числа плавно обновляются при изменении ползунков
- Mobile-first, полностью адаптивный
- Максимальная ширина контента: 720px, выровнен по центру

### 2. Калькулятор сложного процента `/compound-interest`

**Поля ввода:**

| Поле | Тип | По умолчанию |
|---|---|---|
| Начальная сумма ₽  | число | 100 000 |
| Ежемесячное пополнение | число | 10 000 |
| Годовая доходность (%) | ползунок + число | 10 |
| Срок инвестирования (лет) | ползунок + число | 10 |
| Периодичность начисления | выпадающий список | Ежегодно |

**Блок результатов (4 карточки):**
- **Итоговая сумма** — общий капитал на конец срока
- **Вложено** — сумма всех взносов
- **Заработано** — чистая прибыль
- **Доходность** — прирост в процентах

**График:**
- Линейный, два ряда: «С пополнениями» и «Без пополнений»
- Ось X: годы, ось Y: сумма в рублях/евро
- Библиотека: `recharts`
- Стиль: минималистичный, монохромный

**Таблица по годам** (сворачиваемая):
- Год | Баланс | Вложено | Прибыль

**Формула:**
```
A = P(1 + r/n)^(nt) + PMT × [((1 + r/n)^(nt) - 1) / (r/n)]

P   = начальная сумма
r   = годовая ставка (десятичная)
n   = периодичность начисления в год
t   = срок в годах
PMT = ежемесячное пополнение × 12 / n
```

**SEO meta:**
```
title:       Калькулятор сложного процента — как растут инвестиции
description: Рассчитайте, как растут ваши инвестиции с учётом
             ежемесячных пополнений и реинвестирования процентов.
```

**Текст под калькулятором (важно для SEO):**
3–4 коротких абзаца:
- Что такое сложный процент
- Почему он важен для долгосрочного инвестора
- Пример: 100 000 ₽ под 10% на 20 лет = X
- Ссылка на FIRE-калькулятор

### 3. FIRE-калькулятор `/fire-calculator`

**Поля ввода:**

| Поле | Тип | По умолчанию |
|---|---|---|
| Текущий возраст | число | 30 |
| Желаемый возраст выхода | число | 50 |
| Текущие накопления | число | 500 000 |
| Ежемесячные расходы | число | 80 000 |
| Ожидаемая доходность (%) | ползунок | 10 |
| Ставка изъятия (%) | ползунок | 4 |
| Инфляция (%) | ползунок | 5 |

**Блок результатов:**
- **FIRE-число** — сколько нужно накопить (крупно, главный показатель)
- **Нужно откладывать в месяц** — чтобы выйти в нужный срок
- **Лет до FIRE** — при текущем темпе сбережений
- **Прогноз портфеля к пенсии**

**Формула:**
```
FIRE-число = Годовые расходы / Ставка изъятия
Годовые расходы = Ежемесячные расходы × 12 × (с поправкой на инфляцию)
```

**График:**
- Площадной (area chart): рост портфеля год за годом
- Пунктирная горизонтальная линия: FIRE-цель
- Отмечена точка пересечения (момент финансовой независимости)

**Текст под калькулятором:**
- Что такое FIRE
- Правило 4%: откуда взялось и как работает
- Применимость для жизни в России и Европе
- Ссылка на калькулятор сложного процента

## Общие компоненты

### `<Header />`
- Слева: название сайта (моноширинный шрифт, мелко)
- Справа: навигация — Калькуляторы | Блог
- Мобильная версия: гамбургер-меню

- Ссылки: Главная | Калькуляторы | Блог | Дисклеймер
- Дисклеймер: «Сайт носит информационный характер и не является финансовой рекомендацией.»
- Копирайт

### `<ResultCard />`
Пропсы: `label`, `value`, `subtitle?`, `highlight?: boolean`
При `highlight=true`: крупный шрифт, выделяется визуально.

### `<InputSlider />`
Числовой инпут + ползунок, синхронизированы между собой.

## Заглушки для монетизации

Добавить пустые `<div>` — потом заменим на AdSense или партнёрские баннеры:

```html
<!-- Под шапкой, над калькулятором -->
<div id="ad-top"></div>

<!-- Под результатами -->
<div id="ad-mid"></div>

<!-- Под статьёй -->
<div id="ad-bottom"></div>
```

Также под каждым калькулятором добавить блок:
```
Ищете брокера для инвестиций?
[Сравнить брокеров →]   ← ссылка на партнёрскую статью
```

## SEO-требования

На каждой странице обязательно:
- Уникальный `<title>` (50–60 символов)
- Уникальный `<meta name="description">` (150–160 символов)
- Один `<h1>` на страницу
- Иерархия `<h2>` и `<h3>`
- `lang="ru"` на теге `<html>`
- Canonical URL
- Open Graph теги

`robots.txt`:
```
User-agent: *
Allow: /
Sitemap: https://yourdomain.com/sitemap.xml
```

Автогенерация `sitemap.xml` через Next.js.
